# Platform limits for ad copy

Character counts include spaces and punctuation. "Recommended" means the length that shows in full on most placements; longer text gets truncated. Platforms change these often, so check the ad platform's own spec page before launch.

Last checked: September 2026.

## Google Ads responsive search ads (RSA)

| Field | Limit | Notes |
|---|---|---|
| Headline | 30 characters, hard limit | Up to 15 headlines per ad; Google shows up to three at a time |
| Description | 90 characters, hard limit | Up to four descriptions per ad; Google shows up to two at a time |
| Display path | 15 characters each, two paths | Appended to the display URL |

Google assembles headlines and descriptions in any order. Each asset must read cleanly on its own and next to any other.

## Meta (Facebook and Instagram) feed ads

| Field | Recommended | Notes |
|---|---|---|
| Primary text | 125 characters | Text beyond roughly 125 characters hides behind "See more" |
| Headline | 40 characters | Longer headlines truncate on many placements |
| Description | 30 characters | Not shown on every placement |

## LinkedIn single image ads

| Field | Recommended | Maximum |
|---|---|---|
| Introductory text | 150 characters | 600 characters; truncates on mobile after roughly 150 |
| Headline | 70 characters | 200 characters; truncates after roughly 70 |
| Description | 100 characters | 300 characters; only shown on LinkedIn Audience Network |

## Microsoft Advertising

Responsive search ads mirror Google: headlines 30 characters, descriptions 90 characters.

## How the word-count formats map to platforms

- **10-word headline** (Core Benefit + Objection Crusher): fits Meta headlines when short, LinkedIn headlines, landing page heroes, and email subject lines. Too long for one Google RSA headline.
- **35-word description** (Problem to Solution to Benefit): fits Meta primary text and LinkedIn introductory text, though it will usually run past the 125 to 150 character fold. Front-load the product and problem so the visible part still works.
- **Google RSA**: split the formulas across assets. See each skill's "Platform mode" section.
